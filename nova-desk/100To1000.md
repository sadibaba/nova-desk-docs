## Node.js Cluster — Ekdum Simple Language Mein

###  Problem:
Node.js **single-thread** hai. Matlab ek hi engine sab requests handle karta hai. 300 users aaye toh engine busy ho jata hai → timeouts.

###  Solution: Cluster
Node.js ko **multiple copies** mein chalao (jitne CPU cores hain). Har copy alag thread pe chalegi.

---

##  Example:

| Without Cluster | With Cluster |
|-----------------|--------------|
| 1 CPU core use  | **8 CPU cores** (example) |
| 300 users = slow| 300 users ÷ 8 = **~38 users per core** |
| Timeouts        | Fast  |
